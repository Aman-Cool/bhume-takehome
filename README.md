## The approach

Official cadastral boundaries in Maharashtra are georeferenced old paper maps — they sit metres off the real fields due to sparse or ambiguous control points during the MRSAC digitisation. My method finds that offset per plot using the auto-detected field-edge signal in `boundaries.tif` and a normalised cross-correlation.

### Why cross-correlation

The boundaries raster shows where real field edges are visible from satellite. If I rasterise the official plot outline at the same resolution and compute the cross-correlation between that edge mask and the boundaries signal, the translation that maximises edge overlap is the shift needed to snap the official outline onto the real field. The peak quality becomes a natural, interpretable confidence: it measures what fraction of the official boundary edges land on detected real edges after the shift.

### Pipeline (`solve.py`)

1. **Area-ratio gate** — compute `drawn_area / (recorded_area + pot_kharaba)`. Far from 1.0× signals a shape mismatch rather than a placement offset; those plots are flagged rather than moved.

2. **Per-plot edge cross-correlation** — for each plot:
   - Read the `boundaries.tif` patch (60 m pad around the official outline)
   - Rasterise the official polygon edge to the same pixel grid (EPSG:3857, ~2.4 m/px)
   - Apply a light Gaussian blur (σ = 1.2 px) to both, for sub-pixel stability
   - FFT-based cross-correlation → peak offset → (dx, dy) in metres
   - Peak fraction = `raw_overlap_at_best_shift / n_edge_pixels` → base confidence

3. **Confidence calibration** — adjusted for:
   - Peak prominence (sharpness vs 95th-percentile background): flat/noisy peaks penalised
   - Shift magnitude: very large shifts (>90 m) penalised
   - Area-ratio deviation from 1.0 (log-scaled penalty)

4. **Global median shift** — derived from high-confidence per-plot corrections (≥20 available) or from example truths as fallback. Moderate-confidence plots blend their per-plot shift toward this median; low-confidence plots are flagged.

5. **Outlier rejection** — per-plot shifts deviating by more than 3×MAD from the median get their confidence halved before final assignment.

### Key judgment calls

- **Flag rather than guess**: plots where the boundaries signal is thin (under canopy, near buildings) give weak correlation peaks. Flagging them keeps calibration honest rather than diluting AUC with confident-sounding noise.
- **Blend, don't hard-switch**: the global shift captures the dominant village-level offset; blending it in for moderate-confidence plots recovers accuracy for plots with noisy per-plot signals.
- **Area ratio before anything**: if the drawn geometry disagrees with the record in area, shifting it won't help — filter these out to prevent spurious corrections.

## Setup

```bash
uv sync
```

## Data

Download village bundles from `hiring.bhume.in/get-started` and unzip into `data/`:

```
data/
  34855_vadnerbhairav_chandavad_nashik/
    input.geojson
    imagery.tif               # not committed (large raster)
    boundaries.tif            # not committed (large raster)
    example_truths.geojson
    predictions.geojson       # generated by solve.py
```

## Run

```bash
uv run solve.py data/34855_vadnerbhairav_chandavad_nashik
```

Pass multiple directories to process more than one village in a single run.
